# Contributing to TaranMidwife

Thank you for your interest in contributing to TaranMidwife.

TaranMidwife is an open-source healthcare technology project maintained by PT Taran Rainmaker Group. We welcome developers, designers, testers, documentation writers, and other contributors.

## Ways to Contribute

- Report reproducible bugs.
- Improve existing documentation.
- Submit code improvements.
- Propose features and enhancements.
- Improve accessibility, usability, and performance.
- Review pull requests.
- Help identify security and reliability issues.

## Before You Start

1. Read the root README.
2. Review `docs/ARCHITECTURE.md`.
3. Check the current project status and roadmap.
4. Search existing issues and pull requests.
5. Open an issue before making large or potentially breaking changes.

## Development Principles

- Keep changes focused and easy to review.
- Follow the conventions of the relevant language and framework.
- Avoid introducing unnecessary dependencies.
- Do not commit secrets, credentials, private keys, or production data.
- Never use real patient data in development or testing.
- Add or update tests when practical.
- Document configuration and behavior changes.
- Preserve existing functionality unless a change is explicitly intended.

## Pull Request Process

1. Fork the repository.
2. Create a descriptive branch.
3. Make your changes.
4. Run relevant tests and quality checks.
5. Update documentation where necessary.
6. Submit a pull request with a clear explanation.

A pull request should explain:
- The problem being addressed.
- The proposed solution.
- How the change was tested.
- Any limitations or risks.

## Community

Be respectful, constructive, and collaborative. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Thank you for helping improve TaranMidwife.
